# AEGIS

AEGIS is a cinematic cognitive-defense interface for detecting synthetic media,
manipulation patterns, and suspicious digital signals.

## Run locally

```bash
npm install
npm run dev
```

Open `/` for the public experience or `/dashboard` for the interactive command
center. The current analysis panels are local UI flows; connect them to the
FastAPI services when the detection models are ready.

## Quality checks

```bash
npm run lint
npm run build
```
